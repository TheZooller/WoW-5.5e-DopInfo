# World of Warcraft 5.5e • D&D 2024 Reference Guide

Интерактивный справочник по адаптации мира World of Warcraft для правил D&D 5.5e (2024).

## 🌐 Онлайн-версия
Сайт доступен на GitHub Pages:
👉 **[https://thezooller.github.io/WoW-5.5e-DopInfo/](https://thezooller.github.io/WoW-5.5e-DopInfo/)**

## 💻 Локальный запуск
Для запуска локально на компьютере запустите `run_local_server.bat` или выполните:
```bash
python start_server.py
```
Также можно просто открыть файл `index.html` напрямую в браузере.
